
Wanderlust

A full-stack hotel and vacation rental web application built with Node.js, Express.js, MongoDB and EJS.

Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- JavaScript
- Cloudinary

Features

- User authentication
- Create and manage listings
- Image uploads
- Reviews and ratings
- Category filtering
